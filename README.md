# sim-ledger

`sim-ledger` models yearly double-entry ledgers with exact signed minor-unit
amounts, year-local accounts, vouchers, postings, and the basic balance check
that every voucher relies on.

The crate is intentionally small at this layer. It names the ledger data shared
by storage, import, reporting, and codec surfaces, and it keeps money as integer
hundredths so equality and sums stay exact.

## Crates

| Crate | Role |
| --- | --- |
| `sim-ledger` | Ledger records, fixed-decimal amount parsing/formatting, and double-entry balance checks. |

## Documentation

`cargo run -p xtask -- simdoc` builds the public documentation lanes:

- API docs: `target/doc/`
- Agent cards: `docs/agents/cards.jsonl` and `docs/agents/card-index.json`
- Human docs: `docs/humans/`
- Contract files: `docs/generated/`

Everything under `docs/` is generated by that command.

## Validation

```bash
cargo fmt --all --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo doc --workspace --no-deps
cargo run -p xtask -- simdoc --check
```
